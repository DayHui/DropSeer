## 一、总原则（三条，别破）

1. **图宁缺毋滥。** 每张图必须回答"它在正文里承担什么"——是给全貌（结构图）、给证据（截图）、还是给停顿（分隔）。回答不了的，删掉。所以一篇框架篇 4 张正文图是上限，不是下限。
2. **程序化资产优先。** 品牌 v2 的 10 张文章插图（PNG）与 6 组系列插图（SVG）已是成品，直接引用即可。**AI 生图不进正文**——它的位置在氛围插图（见 §五 候办）。
3. **不伪造现场。** 允许：抽象结构、意象、分隔。禁止：假终端截图、假数据曲线、假日志。"观测站不编数据"这条命脉，图也不能破例。

## 三、插入写法（发布版 Markdown）

```markdown
![四层失效：按静默度从外到内](../04_素材与配图/品牌视觉/最终版/07_文章插图/文章插图_四类失效.png)
```

- 路径用**相对发布版 Markdown 所在目录**的相对路径，`wenyan publish` 会按路径读取并自动上传微信图床（已实测通过）。
- 图片标题（alt）写**一句话说明它在讲什么**，不写"图1"。
- 图注（如果想加）：目前主题 CSS 未定义图注样式，**建议不加**——图本身是抽象意象，加文字说明反而啰嗦；确需说明的写在正文里。
- 图片样式由主题统一控制（居中、4px 圆角、上下 28px 间距），**不要在编辑器里手调**。

## 五、候办：氛围插图的 AI 生图路线

老板 2026-09-28 记的候办（见 `00_项目纪要/待办清单.md` §四）：后续生图改用本地 **Qwen-Image-2.1**。

- **定位是补充，不是替代**：程序化插图承担"结构与意象"（可复现、与品牌严格一致），AI 生图只承担**氛围插图**这一类。
- **硬约束**：本机 8GB 显存跑不动原尺寸权重，需 GGUF 量化 + 卸载 + 分块 VAE，单图分钟级；不达标就走云卡。
- **红线不变**：不伪造实验现场、不改品牌符号与配色、构造场景图文都要标注。
- **接入顺序**：氛围插图 → 系列插图备选 → 封面（风险最高，最后动）。
