# 禁用词与套话清单（Q1 扫描底表）

> 用法：定稿前全文搜索左列，命中即替换。左列是**禁止**，右列是**可用的替代方向**。
> 来源：上游 `khazix-skills/khazix-writer` 的 L1 禁用词表 + 本号《文风与排版手册》的补充，已按观测站调性筛过一遍。

## 一、AI 标志句式（最高频，一出现就暴露）

| 禁用 | 换成 |
|---|---|
| 说白了 | 说白了→删掉，直接说结论（这个词上游列为"AI 特别爱用"第一名） |
| 这意味着 / 意味着什么？ | 那结果会怎样呢 / 所以呢 / 后果是 |
| 本质上 | 说到底 / 其实 |
| 换句话说 | 你想想看 / 也就是说 |
| 不可否认 | 删掉，改成正面陈述 |
| 值得注意的是 | 删掉，直接说那件事 |
| 不难发现 | 删掉 |
| 综上所述 / 总的来说 | 换成具体的回扣句（回到开头那个场景） |
| 首先…其次…最后 | 用自然转场替代（"更麻烦的是""顺着这个再往下看"） |
| 让我们来看看 / 接下来让我们 | 直接进入，不要报幕 |
| 在这个 X 的时代 / 随着 X 的发展 | 从一个具体的当下事件切入 |
| 深度解析 / 全面解读 / 重磅 / 颠覆 | 用具体事实当标题（"升级后 87% 掉到 71%"） |
| 我认为……值得……（空转） | 直接给判断，加它的依据 |

## 二、本号补充的禁区

| 禁用 | 原因 |
|---|---|
| "震惊""炸裂""杀疯了""不讲武德"等震惊体 | 观测站不做标题党 |
| "赋能""抓手""闭环""对齐颗粒度""组合拳" | 黑话堆砌，读起来像周报 |
| "赋能行业""引领未来""拥抱变化"等空洞趋势口号 | 没有证据的口号 |
| "小编""咱们公众号""求三连""点个赞再看" | 平台营销口吻，不是观测者 |
| "AI 工具""某个模型""相关技术""某大厂" | 空泛；要么给具体名字，要么不给这条信息 |

## 三、结构类禁区（不是词，是形状）

- **不连续罗列 bullet**：超过 3 条罗列就改成散文叙述（对比表、数据表、清单模板除外——那本来就该是表）；
- **不大段加粗**：连续加粗超过 2 行即为过度结构化；
- **不堆小标题**：小标题要有实质性判断，不能是"背景介绍""现状分析"这种目录词；
- **不标题党**：禁疑问句党（"XX 真的要来了吗？"）与悬念断章。

## 四、标点纪律（与上游的差异）

上游禁用冒号、破折号、双引号；我们**限量不禁**：

| 标点 | 我们的规则 |
|---|---|
| 冒号 ： | 技术文列参数、引出代码/日志时可用；一段里不超过 1 处为宜 |
| 破折号 —— | 插入语可用，**全篇不超过 5 处** |
| 引号 | 中文优先「」，技术术语可用 ""；不出现双层引号嵌套 |
| 加粗 | 金句加粗，**一篇 2–3 处**，多了贬值 |
| 情绪标点（。。。？？？= =） | **不用**。那是上游的口吻，不是观测者的 |

## 五、可用口语清单（本号版本）

我们是工程师口吻，不是段子手口吻。可用：

**转场**：说真的 / 坦率讲 / 顺着这个再往下看 / 这块值得单独说说 / 回到刚才那件事
**表达判断**：我自己的感受是 / 我一直觉得 / 这话听着有点刺耳，但 / 我倾向于认为
**承认与不确定**（本号鼓励多用）：这个我还没跑通 / 样本不够，我先不下判断 / 我自己也在摸索 / 这套框架我用了半年，最近发现有个洞 / 说实话，这次结论和我预期相反
**拉近距离**：做这行的应该都有体感 / 你可能也遇到过 / 看到这里你大概会想到
**情绪（克制的）**：我当时愣住了 / 这一下我确实没料到 / 说实话有点泄气 / 想起来还是觉得不对劲

**不用**：太牛逼了 / 这尼玛 / 给我整不会了 / 你敢信？？？ / 弹幕打在公屏上 —— 这些是个人魅力型创作者的语言，与"冷静观测者"的人设冲突。
