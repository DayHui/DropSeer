## 工作流

单篇生产九道工序（详见 [`06_工作流/内容生产SOP.md`](06_工作流/内容生产SOP.md)）：

T1 素材采集（含脱敏与来源标注）→ T2 初稿（预留注入位）→ T3 老板注入思想 → T4 编辑整理 → T5 质检四道（语言/结构/证据/观测者终审，含内容审核 checklist）→ T6 配图排版 → T7 老板终审 → T8 推草稿箱 → **发布（永远人工）** → T9 数据复盘

三个不可省略的人节点：圈选题、注思想、终审发布。老板单篇净投入约 1 小时。

- **多 Agent 分工**：小迪任主编只编排不代笔，采集/写手/编辑/质检/美术/运营六个专项角色执行，写手与质检员强制隔离（详见 [`06_工作流/多Agent分工方案.md`](06_工作流/多Agent分工方案.md)）

- 合规红线：不做全自动发布，AI 生成内容人工把关（平台 2026-03 起严打非真人自动化创作）
- 创作铁律：文章必须含老板本人的思考，AI 只做初稿引擎；工作素材脱敏
- 热点采集：固定信息源与筛选标准见 [`06_工作流/热点采集规程.md`](06_工作流/热点采集规程.md)
