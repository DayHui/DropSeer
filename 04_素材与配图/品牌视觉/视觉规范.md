# 水滴观测站 · 视觉规范 v1.0

> 2026-09-27 由小迪基于《卷首语与定位.md》生成全套视觉资产时沉淀。风格基准：冷静、克制、工程师仪器感，禁营销风。

## 一、核心视觉概念

**水滴 × 黑盒 × 观测环**

- **水滴**：账号名称意象，也是"观测对象"——光滑、透明，但内部藏着不为人知的复杂世界
- **黑盒（深色立方体）**：大模型与 Agent 的不可见内部，风险的藏身之处
- **观测环 / 雷达扫描线**：工程师的仪器感——试探、核验、测量的动作符号
- **琥珀色异常点**：被观测发现的风险信号，全图只允许小面积点缀

## 二、色彩系统

| 角色 | 色值 | 用途 |
|---|---|---|
| 主背景（深空蓝黑） | `#0B1220` | 所有图的基础底色 |
| 主色（水滴青蓝） | `#38BDF8` | 水滴、观测环、线条、发光元素 |
| 点缀色（警示琥珀） | `#F59E0B` | 异常点、风险标记，面积 ≤5% |
| 辅助（浅灰蓝线条） | `#94A3B8` | 结构图边缘线、刻度、细网格 |

**用色纪律**：青蓝永远主导，琥珀只做"风险信号"的语义色，不参与装饰。

## 三、资产清单与使用场景

| 文件 | 尺寸 | 用途 |
|---|---|---|
| `头像_公众号头像_1024.png` | 1024×1024 | 公众号头像、各平台统一头像 |
| `封面_主视觉_水滴落入黑盒.png` | 1536×1024 | 默认封面 / 重要开篇文章 / 账号门面 |
| `封面_热点周报_雷达观测.png` | 1536×1024 | 「热点周报」系列固定封面 |

| `插图_黑盒四类失效.png` | 1536×1024 | 正文插图：四层失效分类学相关文章的心智锚点图 |
| `插图_评测仪表盘.png` | 1536×1024 | 正文插图：评测、度量、横评类文章 |

**封面标题区约定**：三张封面的左侧 1/3 均为负空间，标题文字加在这里。建议用白色（`#F8FAFC`）+ 细体中文字重，右上或左上对齐。

> 注：公众号封面标准比例为 2.35:1（900×383），1536×1024（3:2）发布时需按公众号编辑器裁切，标题区留白已预留，裁切后主体不损。

## 四、系列封面延展规则（后续自行生成时遵循）

固定结构 = 深空蓝黑底 + 右侧主意象 + 左 1/3 标题留白 + 青蓝主导 + 琥珀点缀。

| 系列 | 主意象建议 |
|---|---|
| 技术实战 | 水滴滴落在测试探针/电路/代码网格上 |
| 团队转型 | 多个小水滴编队飞行，一枚人形剪影在观测 |
| 读者案例 | 破碎/变形的水滴，边缘有琥珀裂纹 |
| 同行访谈 | 两枚水滴并置，中间隔一道观测环 |
