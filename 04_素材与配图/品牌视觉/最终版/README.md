## 零、为什么是「三体水滴」

《卷首语》的账号隐喻是「光滑的外壳 ≠ 无懈可击；风险藏于黑盒之中」。而《三体》的水滴是这句话最极致的图像化：

- **极致的美**：一滴完美的水银、圣母的眼泪，纯洁而唯美
- **极致的简**：表面绝对光滑，放大一千万倍依然光滑
- **极致的反差**：最唯美的造物，往往最致命——正是「光滑外壳之下藏着致命」的隐喻

所以主符号只保留**两样东西**：一个完美的水滴形状，和一道镜面反光。**其余全部删掉**——每多一条线，都是对「绝对光滑」的破坏。

### 主符号释义

一滴悬浮在宇宙黑中的**水银**。

- **实心银滴**：头部浑圆、尾部极尖，高宽比 1.61——表面张力下的真实悬滴形状
- **一道镜面高光**：全反射镜面，表面映出一段流畅的光纹（唯一细节，也是唯一「不可简化的细节」）
- **尖端朝上**：水滴将落未落——观测的临界状态；也指向「从黑盒之外」的方向

### 辅符号释义

一个**黑盒**，顶边开了一道缝，里面的点因此显形。不承担对外识别，只出现在黑盒 / 失效 / 风险主题。

## 二、主符号规范

### 2.1 制图规格

| 参数 | 数值（200×200 画布） |
| --- | --- |
| 画布 | 200 × 200，图形纵向占 20 → 172 |
| 尖端（尾部） | (100, 20)，真尖点（贝塞尔在 t=0 处切线垂直，两侧相切于垂线） |
| 底部椭圆（头部） | 中心 (100, 140)，横半径 40 / 纵半径 32（**扁椭圆，ry<rx → 底部收尖、不鼓**），最宽 80，底到 172 |
| 上贝塞尔 | 尖端 → 控制点 (100, 72) → (60, 116) → 最宽点 (60, 140)，右侧镜像 |
| 高光弧 | 悬滴轮廓等比缩放 **0.82**（锚点=底部椭圆中心）的左侧段，参数区间 t∈[0.16, 0.62]，宽 **6** |
| 填充 | 实心（水银银），无描边 |
| 高宽比 | **1.90**（152 / 80），修长悬滴 |
| 曲率 | 相邻段最大转角 **7.5°**（曲率连续，非「圆+直线」拼接） |

**笔画层级（简化后只剩两档）**：主符号无描边（实心）；高光宽 6；辅符号 / 插图内部统一 主 8 / 次 5。

### 2.2 响应式尺寸规则

| 显示尺寸 | 用哪一版 | 文件 |
| --- | --- | --- |
| **≥ 48 px** | 水银悬滴（全，含高光） | `mark_drop.svg` |
| **24 – 48 px** | 水银悬滴（简，去高光） | `mark_drop_simple.svg` |
| **< 24 px** | 不用图标 | 纯色块 + 反白文字 |

### 2.3 留白与最小尺寸

- 安全区：图形四周留白 ≥ 图形高度的 **1/6**
- 组合时，符号与文字间距 = 图形高度的 **1/5**
- 印刷最小尺寸：**10 mm**

### 2.4 禁止

- ❌ 加颈、加波纹、加内轮廓、加中心点、加任何「零件」（绝对光滑 = 极简）
- ❌ 拉伸变形、旋转（尖端必须朝上）
- ❌ 加渐变、发光、阴影、立体感、描边
- ❌ 换用规范外的颜色
- ❌ 用 AI 生成图替代矢量符号（logo 必须来自本脚本）
- ❌ 在亮底上直接用银滴（银在浅底对比不足，亮底场景改用 `mark_drop_ink` 墨版）

## 三、色彩规范

| 色名 | 色值 | 用途 |
| --- | --- | --- |
| **宇宙黑** | `#0A0F14` | **主背景**（黑盒 / 深空）。头像底、封面底 |
| **水银银** | `#D2DBE4` | 水滴主体 / 反白字 / 深底上的线条 |
| **镜面白** | `#FFFFFF` | 高光（全反射镜面） |
| **琥珀** | `#B05A1F` | 风险信号（唯一暖色）。系列名、异常标记 |
| **墨** | `#0E1418` | 单色印刷 / 亮底反白 |

**规则**：背景永远是宇宙黑（黑盒）；一个画面只有一个主色；银滴 + 高光是最核心的形态；**禁止渐变做主视觉**；琥珀只在「风险 / 强调」处小面积出现。

## 六、系列插图规范（观测器物图）

六张一套，连起来是一条观测动线：**探（试探）→ 波（回波）→ 度（度量）→ 迹（链路）→ 罅（失效）→ 录（复盘）**。

| 编号 | 名称 | 意象 | 对应内容系列 / 用途 |
| --- | --- | --- | --- |
| ill_probe | 探 · 试探 | 探针逼近靶环 | 技术实战、第一手实测 |
| ill_wave | 波 · 回波 | 声呐式同心波纹 | 热点周报、行业动态 |
| ill_gauge | 度 · 度量 | 半圆刻度盘 + 指针 | 评测工具横评、质量度量 |
| ill_trace | 迹 · 链路 | 折线轨迹 + 末端空心节点（待核验） | Agent / MCP 链路实测 |
| ill_fault | 罅 · 失效 | 黑盒裂开一道贯穿缝（**优先用琥珀**） | 失效分析、风险主题 |
| ill_log | 录 · 复盘 | 三条观测记录，一条短一截 | 复盘、总结、读者案例 |

制图规则：等宽笔画（主 8 / 次 5）、单色、几何化、圆头端点、留白统一（框长边 9%）。深底场景用水银银，亮底用墨。

## 九、待办与提示

1. **字标转曲**：交付印刷 / 外部设计协作前，中文需转轮廓（或用思源黑体原件）。
2. **主符号动效**：**水滴滴落 + 高光弧扫过表面**，约 2 秒片头——「死神的绣花针」的锐角转向也可作转场隐喻。
3. **商标注册**：图形与文字分开申请，优先 **第 42 类**（技术服务）、**第 9 类**（软件）、**第 41 类**（在线出版）。图形为几何自绘，可登记美术作品著作权。
4. **小尺寸自检**：缩到 32 px 看一次——高光若糊，改用简版。
5. **版本记录**：v1（AI 渲染图）与 v1.1（亮底线描）已废弃，见 `_废弃_初版AI生成/`（可删）。v2 为当前定案。
