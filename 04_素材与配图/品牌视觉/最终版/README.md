## 一、品牌资产清单

| 资产 | 内容 |
| --- | --- |
| 中文主标 | 水滴观测站 |
| 英文主标 | DROPSEER |
| 主符号 | 滴 · 测（垂线 + 空心水滴 + 中心点 + 波纹弧） |
| 辅符号 | 盒 · 见（黑盒 + 顶边缝 + 内部的点） |
| 定位句 | 黑盒之外 · 冷静观测（封面可变位，可替换为系列名） |
| 内容口号 | 不迷信表象的顺滑，于黑盒之外，做一名冷静的观测者。 |

### 主符号释义

一枚**悬滴**——人类最早的精密测量之一（悬滴法：以一滴悬挂的水测表面张力）。

- **垂线**从画布上缘探入：观测**从黑盒之外开始**。这一笔是全标的精神所在
- **空心水滴**：光滑的外壳，未必代表无懈可击；壳是空的，风险不在表面
- **中心点**：风险就停在这一点上，观测也停在这一点上
- **两道波纹弧**：声呐式的试探与回波——**试探、观测、核验**三个动作的仪器感

日晷是最古老的计时仪器，悬滴是最古老的测量仪器——两个 IP 的符号都「一个符号同时扛住古意与仪器感」，但意象、色彩、字体全部错开，不复用。

### 辅符号释义

一个**黑盒**，顶边开了一道缝，里面的点因此显形。

它不承担对外识别，只出现在与「黑盒 / 失效 / 风险 / 不可解释」直接相关的场景（失效分析、风险主题、评测异常），**不抢主标的位置，但让品牌有第二层细节**。

## 二、主符号规范

### 2.1 制图规格

| 参数 | 数值（200×200 画布） |
| --- | --- |
| 画布 | 200 × 200，图形纵向占 14 → 192 |
| 垂线 | x=100，y 14 → 52，粗 **13**，圆头 |
| 水滴圆 | 圆心 (100, 114)，半径 **44**，笔画 **13** |
| 水滴切线 | 自尖端 (100, 52) 向圆作两条切线至切点 (69.0, 82.8) / (131.0, 82.8)，粗 **13** |
| 中心点 | 圆心处实心圆，半径 **11** |
| 波纹弧 | 圆心 (100, 114)，半径 **62 / 78**，角度 40° → 140°（下方），粗 **8** |
| 端点 | 圆头（round cap） |

**等宽纪律**：全品牌主笔画统一 **13**，次笔画（波纹 / 插图刻度）统一 **8**，插图内部统一 **主 8 / 次 5**。粗细一致比形状一致更重要。

### 2.2 响应式尺寸规则

| 显示尺寸 | 用哪一版 | 文件 |
| --- | --- | --- |
| **≥ 48 px** | 滴 · 测（全） | `mark_drop_*.svg` |
| **24 – 48 px** | 滴 · 测（简，**去波纹弧**） | `mark_drop_simple_*.svg` |
| **< 24 px** | 不用图标 | 改用**纯色块 + 反白文字** |

平台对照：公众号头像约 60–120 px → **用全版**；favicon / 列表缩略约 32 px → **用简版**；更小的角标 → **色块字**。

### 2.3 留白与最小尺寸

- 安全区：图形四周留白 ≥ **图形外径的 1/4**（水滴外径约 101）
- 组合时，符号与文字间距 = **外径的 1/5**
- 印刷最小尺寸：**10 mm**（低于此用简版或色块版）

### 2.4 禁止

- ❌ 拉伸变形、旋转（垂线必须垂直，波纹必须朝下）
- ❌ 改笔画厚度、去掉中心点、改波纹角度
- ❌ 加投影、发光、描边、立体感、渐变
- ❌ 换用规范外的颜色（尤其**不要**用深色底做头像——本品牌是亮底单色体系）
- ❌ 与辅符号「盒 · 见」同时出现在同一画面
- ❌ 在小于 48px 时强用全版（改用简版）
- ❌ 用 AI 生成图替代矢量符号做品牌标识（logo 必须来自本脚本）

## 三、色彩规范

| 色名 | 色值 | 用途 |
| --- | --- | --- |
| **黛青** | `#16404D` | **主色**。头像底、封面底、标题、符号 |
| **琥珀** | `#B05A1F` | **副色**。风险信号、重点强调、特别期封面底 |
| **雾白** | `#F4F6F4` | 底色与反白字（「不是白，是雾」） |
| **墨** | `#15191B` | 单色印刷、长文正文 |
| **水青** | `#3E7C8F` | 点缀，限量使用 |

**规则**：一个画面只有一个主色；**色块 + 反白字**是最稳的形态；**禁止渐变做主视觉**；背景永远亮底（深色底仅用于「特别期」整块反转，且需反白字）。

## 六、系列插图规范（观测器物图）

六张一套，连起来是一条观测动线：**探（试探）→ 波（回波）→ 度（度量）→ 迹（链路）→ 罅（失效）→ 录（复盘）**。

| 编号 | 名称 | 意象 | 对应内容系列 / 用途 |
| --- | --- | --- | --- |
| ill_probe | 探 · 试探 | 探针逼近靶环 | 技术实战、第一手实测 |
| ill_wave | 波 · 回波 | 声呐式同心波纹 | 热点周报、行业动态 |
| ill_gauge | 度 · 度量 | 半圆刻度盘 + 指针 | 评测工具横评、质量度量 |
| ill_trace | 迹 · 链路 | 折线轨迹 + 末端空心节点（待核验） | Agent / MCP 链路实测 |
| ill_fault | 罅 · 失效 | 黑盒裂开一道贯穿缝（**优先用琥珀**） | 失效分析、风险主题 |
| ill_log | 录 · 复盘 | 三条观测记录，一条短一截 | 复盘、总结、读者案例 |

### 制图规则（保证「像一套」）

1. **等宽笔画**：画布 240×240，主笔画统一 **8**、次笔画统一 **5**。
2. **只用单色**：一张图只用一个色，不描边、不填色块、不做渐变。黛青 / 琥珀 / 反白 / 墨 四色皆可。
3. **几何化，不写实**：不画水滴的高光、不画雷达屏、不画刻度数字——只留最少的几何关系。
4. **留白统一**：内容外接框四周留白为框长边的 9%，保证并排时视觉重量一致。
5. **圆头端点**，与主符号「滴」一致。

### 用法

| 场景 | 用哪张 |
| --- | --- |
| 公众号文章头图 | 按选题：实测用「探」，失效用「罅」，评测用「度」 |
| 周报固定角标 | 波 · 回波 |
| 章节分隔 | 任意一张，居中做视觉停顿 |
| 系列封面底纹 | 反白版（`*_on_teal`） |
| 六张按动线排成时间轴 | 季度回顾长图 |

## 八、与《时空茶馆》的边界（防止品牌混同）

| 维度 | 水滴观测站 | 时空茶馆（对照） |
| --- | --- | --- |
| 主符号 | 滴 · 测（水滴 + 垂线 + 波纹） | 晷 · 影（日晷圆盘 + 指针） |
| 主色 | 黛青 `#16404D` | 藏青 `#14304F` |
| 副色 | 琥珀 `#B05A1F` | 朱砂 `#A8362A` |
| 中文主标字体 | 思源黑体 Heavy（现代仪器感） | 思源宋体 Heavy（古典文气） |
| 分隔线母题 | 线 + 三道刻度（量尺） | 线 + 中心点 |
| 气质 | 冷静工程师 · 观测仪器 | 古意茶馆 · 时间容器 |

**纪律**：两个 IP 不共用符号、色值、字体、话术；唯一允许的协同是「制作方法论」层面的分享，不做品牌互导。

## 九、待办与提示

1. **字标转曲**：交付印刷 / 外部设计协作前，中文需转轮廓（或用思源黑体原件）。
2. **主符号动效**：**水滴滴落 + 波纹依次扩散 + 中心点点亮**，约 2 秒片头；素材结构天然支持逐帧动画。
3. **商标注册**：图形与文字分开申请，优先 **第 42 类**（技术服务 / 技术研究）、**第 9 类**（软件）、**第 41 类**（在线出版 / 教育培训）。图形为几何自绘，无第三方字库 / 素材依赖，可登记美术作品著作权。
4. **小尺寸自检**：印刷前把图标缩到 32 px 看一次——若波纹已糊，改用简版。
5. **初版已废弃**：2026-09-27 首版为 AI 渲染图（深底 + 发光 + 渐变），与本人「亮底 + 单色 + 精确制图」的设定相反，已移入 `_废弃_初版AI生成/`，如需清理可直接删除该目录。
