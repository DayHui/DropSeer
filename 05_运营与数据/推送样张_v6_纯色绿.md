# Agent 的四种死法（一级标题示例）

日志是空的，它却写出了第 3847 行。

这是观测 Agent 一段时间后，给我留下最深印象的一类时刻。

## 一、输出层失效：幻觉，它说得越流畅，你越要小心

最外层的失效，发生在答案出口。**错误的答案穿着正确答案的衣服。**

它难测，因为幻觉不抛异常。如果你的断言是"输出不为空""格式正确"，它永远通过。

## 二、执行层失效：工具调了，但调错了地方

第二层往里走一步，问题不在它说的话，而在它做的事。

整个过程里没有任何一步抛出异常，**所以你只能看轨迹，不能只看终点**。

## 三、一张速查表（顺带看表格）

| 失效层级 | 静默度 | 对应评测手段 |
|---|---|---|
| 输出层 | 高 | 事实一致性、引用核验 |
| 执行层 | 高 | 轨迹断言、参数校验 |
| 决策层 | 中 | 路径评测、过度代理红队 |
| 时间层 | 极高 | 回归套件、度量基线 |
