### 原始ID vs AppID（别混，本节存在的唯一理由）

| | 原始ID | AppID |
|---|---|---|
| 形如 | `gh_` + 12 位 | `wx` + 16 位十六进制 |
| 从哪看 | 后台【设置与开发】→【公众号设置】→ 账号详情 | 后台【设置与开发】→【基本配置】→ 公众号开发信息 |
| 用途 | 标识账号；拼主页/历史消息链接；第三方平台绑定 | **调接口**（推草稿箱、素材、菜单 API 都要它） |
| 敏感性 | 半公开（图文的 `__biz` 就是它的 base64） | 敏感，配合 AppSecret 可操作账号 |
