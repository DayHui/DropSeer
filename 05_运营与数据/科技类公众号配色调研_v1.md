## 一、头部账号的实际品牌色（源码实测）

| 账号 | 品牌主色 | 实测色值 | 取法 |
|---|---|---|---|
| **量子位** | **青绿（Teal）** | `#1DA69A`（深一档 `#098C81`，浅一档 `#65BFB7`） | `qbitai.com` 主题 CSS（`liangziwei` 主题）中饱和度最高的非灰阶色，出现频次最高 |
| **机器之心** | **红** | `#EB2835`（出现 123 次，为全站最高频彩色） | `cdn.jiqizhixin.com` 主 CSS |
| **量子位（正文辅助）** | 蓝 | `#0062FF` / `#007EFF` | 机器之心 CSS 中的链接蓝 |

**关键发现：量子位用的不是蓝色，是青绿（Teal）。** 这解释了"你看看量子位的那种"——它的品牌色介于蓝与绿之间，冷、亮、干净，与"技术 / 仪器 / 数据"的气质天然契合。
机器之心则走**单色高饱和**路线（正红），正文全灰阶、只在极少处用品牌红点一下。

> 说明：少数派（sspai.com）与极客公园（geekpark.net）的 CSS 有反爬（403），未取到实测值，故不列入。

## 二、行业通行配色方案（多源核对，结论一致）

| 风格 | 主色 | 强调色 | 适用 |
|---|---|---|---|
| **深空蓝** | `#0D1B2A` / `#1B2838` | **`#4CC9F0` / `#00B4D8`** | AI 工具评测、技术深度 |
| 暗夜金 | `#1A1A2E` / `#16213E` | `#E2B714` / `#F4A261` | 产品发布、重磅对比 |
| 极简灰 | `#F5F5F5` / `#EEEEEE` | `#333333` / `#E74C3C` | 教程指南、清爽风格 |
| 渐变紫 | `#667EEA` → `#764BA2` | — | 未来感、AI 趋势 |
| 终端绿 | `#0C0C0C` / `#1E1E1E` | `#00FF41` / `#39FF14` | 编程相关、Hacker 风 |

**三条被反复强调的规律**
1. **全文配色不超过 3 种**；科技类偏好**低饱和 + 高对比**；
2. 正文用**深灰而非纯黑**（`#3F3F3F` 一类），纯黑在手机屏上对比过强、显硬；
3. 2025–2026 的趋势是**哑光宝石色 / 莫兰迪色系**——即"低饱和、带灰调"，而不是明亮刺眼的纯色。

## 三、把结论套回我们的品牌约束

我们已有的色板（`build_dropseer_assets.py` 定义，品牌 v2）：

| 色 | 值 | 用途 |
|---|---|---|
| 宇宙黑 void | `#0A0F14` | 主背景（黑盒 / 深空） |
| 水银银 silver | `#D2DBE4` | 水滴主体 / 反白字 |
| 冷雾白 paper | `#F7F9FA` | 亮底 |
| 墨 ink | `#0E1418` | 单色 / 亮底反白 |
| 琥珀 amber | `#B05A1F` | 风险信号（**唯一暖色，已确认不适合作正文强调色**） |

**两个有利条件**
- 品牌色调是**冷调**（黑 + 银），与青绿 / 亮青同族，不打架；
- 系列插图线里**早已产出 teal 变体**（`ill_*_teal.svg` / `ill_*_on_teal.svg`），说明青绿在体系内不是外来色。

**已排除的选项**：琥珀（暖、无科技感）、纯蓝 `#1A73E8`（太像链接蓝 / 通用网站蓝，缺乏辨识度）、纯绿 `#00A96E`（与本号"绿灯＝通过"的语义撞车——001 里就有"昨天的绿灯，今天的红灯"）。

## 四、推荐方案（两个候选）

| 方案 | 色值 | 依据 | 气质 |
|---|---|---|---|
| **A · 青绿（量子位同款方向）** | **`#1DA69A`** | 头部账号实测在用的色系；冷调；与水银同族；插图线已有 teal 变体 | 干净、克制、有仪器感 |
| **B · 电光青** | **`#00B4D8`** | 行业"深空蓝 + 亮青"方案的标准强调色；更亮、更"数据感" | 明亮、锐利、科技感更强 |

两版都已做成样张推到草稿箱（标题：【排版样张 v7·青绿】/【排版样张 v7·电光青】），结构完全相同，只换竖条颜色。

**我的建议是 A（青绿 `#1DA69A`）**：同行已经在用、冷调统一、亮而不刺眼，且在"高级"与"科技感"之间更平衡。B 更抢眼，如果嫌 A 太安静就用 B。
