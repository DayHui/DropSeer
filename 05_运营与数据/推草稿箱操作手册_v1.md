## 二、两条路径（按凭证是否配好选）

### 路径 A｜自动推草稿箱（凭证齐全后）

```bash
# 首次：交互式存一次凭证（AppID + AppSecret），之后无需再输
wenyan credential -s

# 推送（本机需先让 wenyan 进 PATH）
export PATH="$PATH:/c/Users/17783/.workbuddy/binaries/node/versions/22.22.2-3"
cd "C:/code/personal/dropseer/03_稿件/001-Agent的四种死法"
wenyan publish -f "001-Agent的四种死法-发布版.md" -t lapis -h solarized-light
```

**成功后的回报**（T8 要求）：草稿箱链接 + 上传图清单 → 记入 `05_运营与数据/` 当日记录。

## 三、老板要做的两件事（各约 2 分钟）

**1. 取 AppID / AppSecret**
微信公众号后台 → 左下【设置与开发】→【基本配置】→ 开发者 ID 区 → 复制 AppID；AppSecret 点【重置】后生成（**只显示一次，务必当场保存**，切勿提交进 git）。

**2. 加 IP 白名单**
同一页【IP 白名单】→ 添加本机公网 IP（`curl ifconfig.me` 可查；切换网络后要重新加）。
不加白名单会直接报 `ip not in whitelist`，这是最常见的失败。

**凭据存放纪律**：用 `wenyan credential -s` 存到本地配置，**不写进项目任何文件**（`.gitignore` 已排除 `.env`）。

## 四、发布版稿件的前置格式（wenyan 强制要求）

发布版 Markdown 顶部**必须**有完整 frontmatter，`title` 与 `cover` **缺一不可**（实测：只给 title 会报"未能找到文章封面"）：

```markdown
---
title: Agent 的四种死法：一个观测者的失效分类学
cover: ../../04_素材与配图/品牌视觉/最终版/04_成品/封面_公众号_900x383.png
---

正文……
```

**从初稿到发布版要做三件转换**（T6/T7 阶段的活）：
1. 删除全部 `[注入位]` 引用块
2. 加 frontmatter（title / cover）
3. 配图占位标记替换为成品图（品牌 v2 资产）

## 五、待办：主题与品牌视觉 v2 的落差（T6 项，不阻塞 T8）

目前只能用内置主题（`lapis` / `phycat` / `default`），**与品牌视觉 v2（宇宙黑底＋水银反白）不一致**。
建议做一份**自定义主题 CSS** 给公众号正文用——注意**正文不能黑底**（长文阅读受不了），做法是：

- 底色保持白，把**强调色限定在水银灰阶**（`#9AA0A6` / `#3C4043` 一类），呼应 v2 而不喧宾夺主；
- 一级/二级标题用 v2 的宇宙黑（`#0E0E10`）；
- 表格边框取灰阶，别用彩色；
- 存成 `05_运营与数据/主题/dropseer.css`，推送时用 `-c` 指定。

这条做完，公众号排版才算与视觉体系收口。

## 六、故障排查

| 报错 | 原因 | 处理 |
|---|---|---|
| `ip not in whitelist` | 公网 IP 未加白名单（或换了网络） | 后台加 IP |
| `未能找到文章封面` / `title is required` | frontmatter 缺 `cover` 或 `title` | 补齐 frontmatter（见 §四） |
| `WECHAT_APP_ID is required` | 凭证未配置 | 先跑 `wenyan credential -s` |
| `wenyan: command not found` | 不在 PATH | 用 §二 的 `export PATH` 那行 |
| 图片没上传 | 走的 render 路径 | 手动在编辑器里传图；或改用 publish（凭证配好后） |

## 七、合规边界（重申）

- **推草稿箱可以半自动，发布必须人工**——老板在手机端过一眼再点发布，约 10 秒；
