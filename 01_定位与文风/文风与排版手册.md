### 各家最好文章的写法拆解

**卡兹克（个人号天花板，学他的"活人感"纪律）**
- 已把写作方法论开源成 skill：四层自检体系（L1 硬性规则→L2 风格一致性→L3 内容质量→L4 活人感终审）
- 三句话内进主题；节奏稳（不一段长一段短）；口语化但不是书面语换皮
- 七条绝对禁区：套话、过度结构化、标点滥用（冒号破折号双引号堆砌）、AI 标志性词汇、假设性例子、空泛工具名、教科书式开头
- L4 终审一问："读完感觉是一个有见识的普通人在认真聊一件打动他的事，还是 AI 在输出信息？"
- 运营指标（成熟期）：常读用户比例≈30%，点赞率 2.5%，转发率 8%，完读率 30%
- AI 分工边界：AI 做找证据/找类比/扩写/补背景；人做第一手观察/核心角度/情绪真实表达

**宝玉xp（工程师写法的标杆，学他的"可复现"）**
- 工程师视角，可运行、可复现优先；每逢大模型发布第一时间跟进+实操心得
- 深入浅出：技术密度不打折，但一般人能看懂
- 转译不是机翻，是理解消化后的意译——引用外部资料时重述成本号语言
- 代表作《AI 原生思维》：用自己三年的真实项目串起方法论，全程一手经验

**机器之心/量子位（媒体写法，只学结构不学腔调）**
- 优点：重大发布的技术拆解结构清晰、图表化表达
- 不学：资讯腔、快讯腔——那是团队媒体的生存方式，个人号写资讯必死

## 二、水滴观测站文风规范

### 人设坐标

- 卡兹克是"AI 殿堂的门童"，宝玉是"前沿的翻译官"，**水滴观测站是"黑盒之外的观测者"**
- 姿态：平视读者，像给同行看实验记录，不是导师训话、不是资讯播报
- 温度：冷静但不冷冰冰——允许一句自嘲、一次真实的挫败感，那是活人感的来源

### 标题

- 格式参考：《Agent 的四种死法：一个观测者的失效分类学》——主标题抓人 + 副标题定调
- 用具体名词和数字，不用空泛大词（"深度解析""全面解读""重磅"禁用）
- 标题里最好有一个"观测"动作或"失效"事实，别用疑问句标题党

### 开头

- 三句话内进主题（学卡兹克）
- 首选两种起手式：
  1. **认知反转式**：第一句打破读者预设（"你以为在测 Agent，其实你在测 LLM"）
  2. **现象直击式**：第一句给一个具体失败现场（"日志是空的，它却编出了第 3847 行"）
- 禁止"随着……的发展""在当今……时代""近年来"开头

### 正文

- 段落短，3–5 行一段；单段不超过 6 行
- 每个论断都要有证据类型标注：实测数据 / 公开引用 / 构造场景（构造必须声明，这是本号生命线）
- 小标题用编号 + 一句话判断（"二、执行层失效：每一步都'成功'，结果是错的"），标题本身就是论点
- 金句适度加粗，一篇 2–3 处，多了就贬值
- 对比内容用表格，实测数据用表格，过程描述用文字——别拿文字硬描述数据
- 引用外部概念正常署名（Anthropic 的 Outcome/Transcript 等），重述成自己的语言再引用原文
- 语气词纪律：口语化允许（"跑了五遍，第五遍才对"），网络梗慎用（观测站不做玩梗人设）

### 结尾

- 文学性收尾 1–2 句（呼应卷首语气质："愿所有的探索，从这一次次观测开始"）
- 固定栏目化收尾：预告下一篇观测对象 / 留一个开放问题给评论区
- 资料钩子（可选）：失效检查清单、选型决策树等，引导后台回复领取

### 排版（公众号正文规范 v1.2，2026-09-27 定）

> **唯一实现 = `05_运营与数据/主题/dropseer.css`**（wenyan 推送时用 `-c` 指定）。要改排版就改这个文件，**不要在公众号编辑器里手调**——手调无法复现，也无法同步到下一篇。

| 项 | 取值 | 为什么 |
|---|---|---|
| 正文字号 | **15px** | 头部账号通行尺寸；信息密度更高，留白才显得从容 |
| 正文颜色 | **#39424A 深灰** | 纯黑在手机屏上对比过强、显硬；深灰柔和但不减可读性 |
| 行高 | **1.85** | 舒适区 1.75–2.0；长文取偏大值 |
| 字间距 | **0.5px** | 中文正文天生偏紧，这一点点空气感很关键 |
| 段间距 | **20px**（上下） | 靠间距而非缩进分段；**首行不缩进** |
| 两端缩进 | **12px** | 微信默认 0，贴边是"粗糙感"的第一来源 |
| 一级标题 | 20px / 700 / #0F1317，**居中**，上 52px 下 26px，下方一条**极淡**细线（#E9EEF2） | 章节感靠"居中 + 大留白"建立，不靠色块 |
| 二级标题 | 17px / 700 / #0F1317，上 38px 下 18px，左侧一条 **2.5px 琥珀细线** | 全文**唯一**的彩色装饰点，只用来标层级；不用色块、不用底色 |
| 三级标题 | 15.5px / 700 / #2A333B | 比二级再浅一档 |
| 加粗 | 只加重量、不提色（#0F1317，比正文黑一格） | 全文强调靠灰度差，不靠颜色 |
| 引用块 | 浅灰底 #F7F9FA + 1px 银灰左线（#C9D2DB）+ 4px 圆角 | 给灰阶一点层次，不引入第二种彩色 |
| 表格 | 只留横线（表头底 #F4F7F9，行线 #EFF3F6），字号 14px | 微信里最不容易塌的画法 |
| 图片 | 居中、4px 圆角、上下 28px 间距 | 图与文之间要留足空气 |
| 分隔线 | 48% 宽、#EDF1F4，一篇文章 3–5 处 | 极淡且短，只做视觉停顿 |
| **配色纪律** | 正文灰阶三色（#0F1317 / #39424A / #5A646D + 浅灰底）＋**琥珀仅一处**（二级标题左线） | "简约才是高级"；琥珀是品牌唯一暖色，除标题左线外只出现在封面与插图 |

**其余规范**：
- 代码/日志用等宽字体代码块，别用普通文字贴；
- 实测文章必备三件套：任务描述表、结果数据表、失败案例截图；
- 首图用品牌 v2 资产的**高清版**（`封面_公众号_高清_1800x767.png`，官方推荐的 900×383 在手机上会被拉伸放大而发糊）；
- 排版完成后**必须手机端预览一次**（公众号的最终呈现以手机为准，电脑端看不出的问题手机上全暴露）。

品牌视觉 v2 已定案（主符号「水银悬滴」+ 辅符号「盒·见」，宇宙黑底 + 水银反白，全部**程序化生成 SVG/PNG**，见 `04_素材与配图/品牌视觉/最终版/`）。配图来源分四类：

2. **文章插图**：用 `最终版/07_文章插图/` 的成套插图（黑盒 / 水滴入黑盒 / 四类失效 / Agent 链路 / 评测仪表 / 观测 / 编队 / 信号波形 / 分隔符）；新插图按 `最终版/_生成脚本/` 的脚本方式**生成，不手绘、不用 AI 渲染**
3. **结构/示意图**：代码绘制（表格、图），**带文字的图不用 AI 生成**（会乱码）
4. **实测截图**：老板提供，真实工作脱敏——AI 不伪造实验现场，观测站不编数据，图也一样；工具截图引官方文档并注明出处

**v2 之后的三条纪律**（替代 v1.0 的"AI 生图原则"）：
- **不引入新颜色、不新造字体**——只用 v2 体系色（宇宙黑底 + 水银反白）与既定字体，要调规格就改脚本常量重跑，不手绘近似版；
- **AI 生图只在没有现成素材且只做氛围时使用**（不放文字、不伪造终端截图与数据曲线）；有品牌资产的一律走程序化生成；
- **成本**：程序化生成为本地零成本（v1.0 记的"每张图约 5–10 积分"是 AI 生图口径，已不适用于主要流程）。

## 三、出厂质检（每篇发布前过四道）

> 这是把卡兹克"四层自检"改造成测试工序——一个讲质量工程的号，文章自己也得过质检。

- **Q1 语言质检**：扫描 AI 味——"说白了/这意味着/首先其次最后/值得注意的是/总而言之"等套话清单；标点堆砌；教科书开头
- **Q2 结构质检**：三句内进题了吗？节奏有没有一段长一段短？小标题是不是论点？结尾有没有收住？
- **Q3 证据质检**：每个关键论断能指认证据类型吗？构造场景标注了吗？引用署名了吗？数据可复现吗？
- **Q4 观测者终审**："读者读完，感觉是一个工程师在展示他的观测记录，还是一个资讯号在搬运信息？"——答不出前者就回炉

## 四、数据目标（健康度指标，不是 KPI）

- 完读率 ≥30%（卡兹克成熟期水平，新号先奔 25%）
- 点赞率 ≥2%，转发率 ≥5%（转发 = 证据有用，是对观测站内容最真实的投票）
- 常读用户比例：半年后 ≥25%
- 唯一北极星：**每篇文章是否提供了别处没有的第一手观测**——有，其他指标自然会来

## 五、待议（2026-09-27 复核提出，等老板定后再并入手册正文）

> 以下四条是我复盘时看出来的，尚未定论，**暂不改动上文规则**。定了再写回对应小节。

**1. 数据目标要分冷启动期与成熟期。**
上表数值取自卡兹克成熟期（均篇 6–7 万阅读）。新号几百阅读时，完读率/点赞率波动极大、参考价值低。
建议：**前 3 个月只看两件事**——这篇有没有第一手观测、转发率多少；其余指标等常读量上来再启用。

**2. 明确"学谁的技法、不学谁的选题"。**
卡兹克与宝玉都是"追发布 + 追热点翻译"的选题方式，本号是"观测者"。
建议补一条写作纪律：**技法（节奏/结构/禁区）学上游，选题只从自己的观测台出**——否则会滑成"又一个 AI 评论号"。

**3. 补一条"失败与不确定的表达规则"。**
观测站最值钱的资产是真实，而"敢承认没测出来"比任何金句都立人设（001 已有此笔法）。
建议在 Q3 证据质检里硬性要求：**每篇至少一处**"我没测出来 / 样本不够先不下判断 / 结论与上次相反"。

**4. 标题策略分两套。**
现规范（具体名词 + 数字、禁大词、禁疑问句党）对主线篇合适，但周报在冷启动期需要更直给的标题。
建议：**主线篇保持克制，热点周报用直给式**（如"本周 7 条信号：XX 出了新版本、XX 翻车"），这是两个不同的阅读场景。
