## 二、定位与文风（02-26 定调）

**一句话定位**：以工程师视角，试探、观测、核验大模型与 Agent 背后的风险——做黑盒之外冷静的观测者。

**核心框架（原创资产）· 四层失效分类学**——直接由卷首语四个风险词展开：

| 层级 | 失效类型 | 静默度 | 对应评测手段 |
|---|---|---|---|
| 输出层 | 幻觉 | 高 | 事实一致性、引用核验 |
| 执行层 | 工具调用错误 | 高 | 轨迹断言、参数校验 |
| 决策层 | 规划失效 | 中 | 路径评测、过度代理红队 |
| 时间层 | 版本退化 | 极高 | 回归套件、度量基线 |

- **文风坐标**：卡兹克是"AI 殿堂的门童"，宝玉是"前沿翻译官"，**我们是"黑盒之外的观测者"**——不拼媒体的快，拼观测记录的不可替代性
- **开头纪律**：三句内进题，认知反转式或现象直击式起手
- **证据纪律**：每个论断标注证据类型（实测/公开引用/构造场景），构造必须声明
- **配图纪律**：AI 图只做氛围不做内容；实测截图必须真实（观测站不编数据，图也不破例）
- **出厂质检四道**：语言 → 结构 → 证据 → 观测者终审

## 三、内容策略与创作铁律

- **选题准入**：每个题目必须答得上"切入的热点是什么 + 我的独有视角是什么"，答不上来的通用水文不写
- **借势落笔**：从热点进场，用 E2E 测试专业体感收回到自己的观测
- **创作铁律**：**AI 出结构与证据，老板出思想**。文章必须含老板本人的思考；纯 AI 稿不发
- **脱敏纪律**：工作素材只写方法、现象、思考，不碰公司名、项目名、数据细节
- **合规红线**：不做全自动发布；AI 内容人工把关后进草稿箱（平台 2026-03 起严打非真人自动化创作）

## 四、内容规划（v1.1，朴实命名）

**顶层逻辑修正**：**个人 IP 是唯一北极星**，付费不进设计主轴（远期可选）。IP 资产重要度：人物 > 原创框架 > 固定仪式 > 栏目名。

**六大内容系列**：

1. **热点周报**——热点搜集+整合，AI 采集、站长筛选点评，每周六固定档
2. **洞察思考**——自己的思考与反共识判断，月 1–2 篇
3. **技术实战**——五条线：GUI Agent 实测 / E2E 测试实战 / 评测工具横评 / 基线档案 / 测试 Agent 设计
4. **团队转型**——带队心得与总结，月 1 篇
5. **读者案例**——读者来稿失效案例分析
6. **同行访谈**（储备）——5000 常读后启动

**技术实战三层叙事弧**：测 Agent（GUI 实测）→ 用 Agent（E2E 测试实战）→ 造 Agent（测试 Agent 设计）

**一鱼三吃切分规则**：实操细节→测试 Agent 设计；思想判断→洞察思考；团队推行→团队转型

**节奏**：周六早周报固定档 + 周中主线篇，每周 2 篇为上限。

**弹药库**：120+ 期选题（十大板块，约两年量），见《各系列选题库.md》。
