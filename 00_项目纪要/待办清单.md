## 四、候办 · 本地生图接入 Qwen-Image-2.1

> **2026-09-28 老板提**：计划后续生图改用**本地部署的 Qwen-Image-2.1**。记录为候办，等有空先做一次最小可行性验证。

**为什么值得做**
- **零边际成本**：不耗积分、不计次；
- **可复现**：可固定种子与参数，同 prompt 出同图——这对"不编数据、图也要能复现"的纪律是加分项；
- **不依赖外部**：云端额度、网络、限流都不再是变量；
- **中文渲染较强**：Qwen-Image 系对中文字形与排版的处理明显强于多数开源模型，未来可能松动"图里不放文字"这条纪律（**但需先验证再改规矩**）。

**⚠️ 当前硬约束（必须先验证，别假设能跑）**
本机 GPU 实测：**NVIDIA GeForce RTX 5060 Ti / 8151 MiB 显存**（驱动 591.55）。
Qwen-Image 是 ~20B 级 MMDiT：bf16 约需 40GB、fp8 约需 20GB → **本机直接跑不动**。

可行路线（按推荐顺序）：
1. **量化 + 分层卸载**：GGUF Q4/Q3 权重 + ComfyUI 的 lowvram / sequential CPU offload + 分块 VAE 解码 —— 能跑，代价是**单图数分钟级**；
2. 若速度不可接受：**租云卡**做批量生成，本地只做小图与调试；
3. 折中：本地只跑"少量关键图"，其余仍走程序化资产。

**未来接入点（建议由轻到重）**
1. **文章氛围插图**（现为 10 张程序化插图，可作补充而非替代）；
2. 系列插图备选（需先过品牌一致性）；
3. 封面元素（**风险最高**：封面是品牌识别核心，动它要过品牌规范，且必须重新出高清版）。

**红线不变（接入前先复述一遍）**
- 不伪造实验现场（假终端、假数据曲线一律不许）；
- **不改品牌符号、不引入新颜色**——主符号「水银悬滴」的规格由脚本常量控制，AI 生成物不得近似替代；
- 构造场景在文中必须标注——**图也一样**；
- 图与正文论点无关就不放（"图宁缺毋滥"）。

**下一步（最小验证，约 1 小时）**
1. 装 ComfyUI + 拉 Qwen-Image-2.1 的量化权重；
2. 用一条品牌色 prompt（宇宙黑底 + 水银意象）跑 1024×1024 单图；
3. 记录三项数据：**显存峰值 / 单图耗时 / 与品牌规范的偏差**；
4. 达标则定接入点与工作流，不达标就走"云卡批量"或维持程序化资产。
