## 归属裁定：E2E 测试 Agent 与 Skill 的设计 → 技术实战 · 测试 Agent 设计

"怎么设计 E2E 测试 Agent 和 skill" 归技术实战第五条线 **测试 Agent 设计**。至此技术实战形成完整叙事弧：

- **测 Agent**（GUI Agent 实测）：观测别人造的 Agent
- **用 Agent**（E2E 测试实战）：用 Agent 干测试主业
- **造 Agent**（测试 Agent 设计）：亲手设计自己的测试 Agent 与技能

**一鱼三吃切分规则**（同一素材写多篇时的归属判断）：
- 写实操细节（架构、SKILL.md 怎么写、工具接口怎么定）→ **测试 Agent 设计**
- 写思想判断（技能化对软件工程意味着什么）→ **洞察思考**
